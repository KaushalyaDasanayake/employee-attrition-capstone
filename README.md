# ‍ Employee Attrition Prediction — Machine Learning Project

## Project Overview

Employee attrition is a major challenge for organizations. This project aims to predict whether an employee is likely to leave the company based on various factors such as job role, salary, work-life balance, and performance.

The goal is to help HR teams take proactive actions to improve employee retention.

---

## Dataset

* Dataset: IBM HR Analytics Employee Attrition Dataset (Kaggle)
* Records: ~1,470 employees
* Features include:

  * Age, Gender, Job Role
  * Monthly Income
  * Job Satisfaction
  * Years at Company
  * Work-Life Balance
* Target variable: **Attrition (Yes / No)**
